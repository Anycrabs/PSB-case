# Что сделать руками

Всё остальное происходит автоматически. На платформе модель, эмбеддинги, реранкер и индекс базы знаний подключаются сами. В Docker модель эмбеддингов скачивается, а индекс строится и загружается в Qdrant при запуске.

Нужно заранее: установленный Docker (Docker Desktop) и Python 3.11+.

## Сабмит на платформу

1. Собрать архив из корня репозитория:

   ```bash
   python submission/build_zip.py
   ```

2. Загрузить `dist/submission.zip` на платформу. Лимит — 5 сабмитов в день, сброс в 00:00 МСК.

Ключи, адрес модели и базу знаний платформа передаёт сама, в архив их класть не нужно.

## Прототип с веб-интерфейсом

Прокси организаторов работает только внутри платформы, поэтому для прототипа нужен свой ключ DeepSeek.

1. Получить ключ: зарегистрироваться на [platform.deepseek.com](https://platform.deepseek.com), пополнить баланс, создать API key.
2. В корне репозитория создать `.env` и вписать ключ в строку `LLM_API_KEY=`:

   ```bash
   cp .env.example .env
   ```

3. Запустить и дождаться, пока `gateway` станет `healthy`:

   ```bash
   docker compose up --build
   ```

   Первый запуск занимает дольше: скачивается модель эмбеддингов (около 2,3 ГБ).
4. Открыть http://localhost:8000.

Без ключа (только чтобы проверить интерфейс): в `.env` указать `EMBEDDER_MODE=fake`, `LLM_BASE_URL=http://fake-llm:9000/v1`, `LLM_MODEL=fake`, затем запустить `docker compose --profile dev up --build`.

## Если организаторы обновили базу знаний

Заменить файл `data/knowledge-base.zip` и перезапустить `docker compose up`.
