# submission_v3 — лучший сабмит (33.125)

Самодостаточная папка: ровно эти файлы лежат в ZIP для платформы (`submissions/submission_v3.zip`).
Собрана от `submission_v2`. Отличаются три файла: `solution.py`, `lc_prompts.py`, `lc_embeddings.py`;
остальные модули `lc_*.py` — без изменений. Код в `legal_core/` (веб-прототип) не затронут.

## Собрать архив

```powershell
Compress-Archive submission_v3\*.py, submission_v3\requirements.txt dist\submission_v3.zip -Force
```

## Что изменено относительно submission_v2

| Файл | Изменение |
|---|---|
| `solution.py` | Вызов модели подстраивается под прокси и запоминает рабочий вариант на весь прогон: 4xx на большой `max_tokens` → значение платформы; пустой или оборванный ответ (рассуждения модели расходуют `max_tokens`) → тот же вопрос с меньшим объёмом рассуждений (`reasoning.effort` low → none), а если прокси поле не принимает — с удвоенным `max_tokens`. Если по темпу первых ответов прогон не укладывается во время, рассуждения уменьшаются для всех вопросов; если это не ускоряет, режим возвращается. `submission.csv` пишется сразу после индекса (текст найденных пунктов, без API) и обновляется каждые 5 ответов. Новые вызовы модели прекращаются на 930-й секунде, выход — не позже 1020-й. При сбое эмбеддингов базы поиск идёт по BM25 и точным ссылкам, а не по хеш-векторам. Автоматическое дописывание оговорок убрано. |
| `lc_prompts.py` | `TEXT_SYSTEM` переписан под формат эталона организаторов: 1–3 предложения, только то, о чём спросили, документ и пункт; без меток `[S#]` и встречных вопросов. Заголовки фрагментов в контексте без меток (`plain_header`). |
| `lc_embeddings.py` | Тайм-аут и число попыток берутся из настроек (45 с на пачку базы, 15 с на вопрос, 2 попытки вместо 120 с × 4). Если прокси отклоняет пачку (400/413/422), её размер уменьшается вдвое и запоминается. |

## Проверка на мок-прокси (18 демо-вопросов)

| Сценарий | v2 | v3 |
|---|---|---|
| 400 на `max_tokens=3000` | 18 ответов модели, 36 вызовов | 18 ответов, 20 вызовов |
| 403 на `max_tokens=3000` | 0 ответов | 18 ответов, 20 вызовов |
| Пустой ответ при рассуждениях по умолчанию | 0 ответов, 108 вызовов | 18 ответов, 20 вызовов |
| Модель не отвечает вообще | 108 вызовов | 34 вызова, ответы текстом пунктов |
| `/embeddings` отдаёт 500 или висит | — | 18 ответов на BM25 |

Поиск не менялся: на `data/eval/bench.csv` нужный фрагмент попадает в контекст в 48 из 48 вопросов даже на одном BM25.
